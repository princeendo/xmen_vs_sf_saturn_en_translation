  product `T-1226G`, version `V1.002`, date `19970925`, `CD-1/1`, area `J`,
  peripherals `JW`, title `X-MEN VS STREET FIGHTER`. MAME 0.289 `saturn.xml`
  lists `T-1226G` as *X-Men vs. Street Fighter (Japan) (Doukonban)* (recorded in
  MSHvSF `references/xmvsf/saturn_jp/README.md`).

  0-71,905 equals, byte for byte, the earlier ISO-plus-MP3 rip held by the
  MSHvSF project (`X-Men vs. Street Fighter.iso`, 147,263,488 bytes, SHA-256
  `e2b65dfdbc81a295daf3ffd8f8a9a315909830912799fc49b98026d9c59acebc`). Sectors
  71,906-71,907 are Mode 1 with all-zero user data. SHA-256 of the user data of
  all 71,908 sectors:
  `23de6a79cae75461231714ef2027146c04c92f299151e04b61bd3f11aa4db107`.
  Method: a script reading bytes 16-2063 of each 2352-byte sector and comparing
  them with consecutive 2048-byte ISO blocks.
- **Identity status: SUPPORTED.** The header, the Redump-style names and the
  layout agree with the named release. No Redump or MAME hash has been compared;
  MAME identifies Saturn discs by CHD, which needs `chdman` to build and compare.

  cartridge. `EMU-005` confirms the emulator configuration.
